# 🧠 ذاكرتي | Thakirati

> **المساعد الشخصي الذكي لتنظيم الأولويات، تتبع أماكن الأغراض، ومنع النسيان.**  
> تطبيق ويب تقدمي (PWA) فائق السرعة، مصمم ليعمل بسلاسة تامة على أجهزة الحاسوب المحمول والآيباد والأجهزة اللوحية والهواتف.

---

## 🌟 الميزات الرئيسية

### 1. 🎯 رادار اليوم المباشر (Today's Radar)
- فرز فوري بين **المهام المحددة بساعة معينة** (مع عدّاد تنازلي وجرس تنبيه) وبين **المهام المفتوحة لليوم**.
- أولويات ملونة واضحة (🔴 عاجل جداً | 🟡 مهم | 🔵 عادي).
- زر إنجاز ميكانيكي مع أصوات نغمات تفاعلية واحتفال بصري ملون (Confetti).
- **لافتة الترحيل الصباحية:** ترحيل تلقائي بضغطة زر لأي مهام لم تُنجز من الأمس حتى لا تضيع.

### 2. 📍 وين حطيت أشيائي؟ (Where Did I Put It?)
- محرك بحث فوري للأغراض وأماكنها الدقيقة (مثال: مفاتيح، جواز السفر، الشواحن، الأوراق).
- بطاقات تفصيلية مقسمة حسب الغرف (غرفة النوم، المكتب، السيارة، الحقيبة...).
- دعم التقاط الصور بالكاميرا للمكان لتذكره بالعين.
- زر سريع لتحديث المكان عند نقل أي غرض.

### 3. ⚡ تفريغ الدماغ والإملاء الصوتي (Brain Dump & Voice Memos)
- صندوق إدخال سريع لتسجيل أي فكرة قبل أن تفلت من الذاكرة.
- **إملاء صوتي عربي (Speech-to-Text):** اضغط على الميكروفون وتحدث بالعربية ليتحول كلامك فوراً إلى نص.
- **تسجيل مذكرات صوتية مباشرة:** الاستماع للملاحظات الصوتية في أي وقت.
- زر لتحويل الملاحظة فوراً إلى مهمة في جدول اليوم.

### 4. 🏆 سجل الإنجاز (Accomplishments Log)
- توثيق كل ما قمت بإنجازه اليوم مع التوقيت بالدقيقة.
- زر **"إنجاز مفاجئ"** لتوثيق أي شيء قمت به دون تخطيط مسبق.

### 5. 📱 دعم كامل للآيباد والأجهزة اللوحية
- تثبيت بملء الشاشة عبر ميزة **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)** في متصفح Safari.
- مساحات لمسية مصممة خصيصاً للمس وأقلام الأجهزة اللوحية.
- العمل دون اتصال بالإنترنت بفضل تقنية **IndexedDB** و **PWA**.

## 🚀 التشغيل والتطوير المحلي

```bash
# تثبيت الحزم
npm install

# تشغيل الخادم المحلي للشبكة
npm run dev -- --host

# بناء حزمة الإنتاج
npm run build
```
